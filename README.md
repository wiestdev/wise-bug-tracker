## Инструкция по локальному запуску

```
cd ./docker
docker compose up -d
```

## Инструкция по настройке для локального запуска

Скопировать .env с .env.example в каждом проекте **(ДАННЫЕ ИЗ DOCKER COMPOSE УЖЕ ВБИТЫ В .env.example)**
